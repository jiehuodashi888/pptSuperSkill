# Enterprise PPT Multistyle

This skill is the distributable entrypoint for the local enterprise PPT framework. It describes the framework boundary without embedding company data, proprietary templates, style values, or source samples.

## Local runtime

Run the minimal command dispatcher with:

```bash
npm run ppt-skill -- help
```

The current runtime exposes only help. `validate-instance` is intentionally deferred to a later task and is not advertised here.
